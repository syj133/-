# 问题三：储能协同优化模型（模型建立与求解）

> 状态：草稿 v0.2。已使用“问题3结果_我跑的”结果包中的真实结果（全时域 0–2406 小时，六区域独立 MILP，HiGHS 精确求解）。章节编号待全文定稿后统一调整。

## 6.1 模型概述

问题三在**给定任务调度与逐时负荷**的基础上，研究储能系统的协同优化作用。按附件 1 的统一口径，问题三不重新优化任务迁移与开工时段，而是以

$$IT\_Load(r,t)=Baseline\_AI\_IT\_Load(r,t)+NonAI\_IT\_Load(r,t),\qquad Total\_Load(r,t)=IT\_Load(r,t)\times PUE(r)$$

作为给定负荷，仅优化**储能充放电、购售电与新能源分配**策略。此时六个区域之间不存在任务或电力耦合，储能协同问题可分解为六个相互独立的区域优化子问题；每个子问题为带 0-1 变量（禁止同时充放电）的混合整数线性规划（MILP），规模为 $T=2407$ 个时段（第 0–2406 小时），可由 HiGHS 求解器精确求解。

模型以运行成本、碳排放、区域峰值净购电功率与负荷波动程度为评价指标，通过**逐目标最优 + 两阶段字典序求解**与**加权归一化综合权衡**两类方式生成多组策略，并与附件基准状态对比，定量刻画储能系统对四项指标的影响；在此基础上进一步开展储能容量与充放电效率的敏感性分析，验证模型结论的稳健性。

## 6.2 模型假设

1. **负荷固定假设**：给定 IT 负荷取附件 `Baseline_AI_IT_Load_MW + NonAI_IT_Load_MW`，设施负荷按区域 PUE 折算，问题三不调整任务调度，故负荷为外生参数。
2. **区域独立假设**：六个区域之间不存在线路潮流、带宽与传输费用（问题说明第 7 条），储能协同问题按区域独立求解。
3. **储能运行假设**：充放电功率在小时内恒定，充/放电效率取附件固定值；同一时段不允许同时充放电，以 0-1 变量强制；忽略储能自放电率（附件口径未包含）。
4. **新能源分配假设**：可用新能源可在直接消纳、储能充电、外送与弃电之间自由分配；弃电无惩罚成本，外送受 `SellLimit` 约束。
5. **市场假设**：购电按逐时电价、外送按区域售电价结算，均不含阻塞、无功与爬坡等电力系统细节；购电与售电互不转售（外送仅限新能源）。
6. **时域假设**：主时域为第 0–2399 小时，第 2400–2405 小时用于结清末端负荷并计入能源/成本/碳排放结算，第 2406 小时仅用于电力与储能终端状态结算；要求 $S(2406)\ge S^{0}$。

## 6.4 模型建立

### 6.4.1 集合与参数

见 6.3 符号说明，所有参数均取自附件 `region_time_data.xlsx`、`storage_information.xlsx` 与 `GPU_information.xlsx`。

### 6.4.2 决策变量

对每个区域 $r$、时段 $t$ 定义：

$$gp_{r,t}\ge 0,\ gs_{r,t}\ge 0,\ d_{r,t}\ge 0,\ rc_{r,t}\ge 0,\ gc_{r,t}\ge 0,\ c_{r,t}\ge 0,\ p_{r,t}\ge 0,\ S_{r,t}$$

以及 0-1 变量 $y_{r,t}$（1 表示时段 $t$ 处于充电状态、0 表示放电状态）。

### 6.4.3 约束条件

**（1）新能源分配平衡。** 可用新能源在直接消纳、储能充电、外送与弃电之间分配：

$$d_{r,t}+rc_{r,t}+gs_{r,t}+c_{r,t}=R_{r,t},\quad \forall r,t$$

**（2）功率平衡。** 购电、直接消纳新能源与储能放电共同满足负荷与电网充电：

$$gp_{r,t}+d_{r,t}+p_{r,t}=L_{r,t}+gc_{r,t},\quad \forall r,t$$

**（3）储能 SOC 动态。** 按附件 1 口径递推，初始状态为 $S^{0}_{r}$：

$$S_{r,t}=S_{r,t-1}+\eta^{c}_{r}(rc_{r,t}+gc_{r,t})-\frac{p_{r,t}}{\eta^{d}_{r}},\quad S_{r,-1}=S^{0}_{r}$$

**（4）SOC 上下限与终态约束。**

$$\underline{S}_{r}\le S_{r,t}\le \overline{S}_{r},\qquad S_{r,2406}\ge S^{0}_{r}$$

**（5）储能功率约束与充放电互斥。**

$$rc_{r,t}+gc_{r,t}\le \overline{P}^{c}_{r},\quad p_{r,t}\le \overline{P}^{d}_{r}$$
$$rc_{r,t}+gc_{r,t}\le \overline{P}^{c}_{r}y_{r,t},\quad p_{r,t}\le \overline{P}^{d}_{r}(1-y_{r,t}),\quad y_{r,t}\in\{0,1\}$$

**（6）购售电边界。**

$$0\le gp_{r,t}\le \overline{G}^{in}_{r},\qquad 0\le gs_{r,t}\le \overline{G}^{out}_{r}$$

### 6.4.4 目标函数：多目标与加权综合

四项评价指标（全时域 $t\in\mathcal{T}$）：

$$f_{1}=\sum_t\left(\pi_{r,t}gp_{r,t}-s_{r,t}gs_{r,t}\right)\quad(\text{运行成本})$$

$$f_{2}=\sum_t \sigma_{r,t}gp_{r,t}\quad(\text{碳排放})$$

$$f_{3}=\max_t\left(gp_{r,t}-gs_{r,t}\right)\quad(\text{区域峰值净购电})$$

$$f_{4}=\frac{1}{|\mathcal{T}|}\sum_t\left|gp_{r,t}-gs_{r,t}-\overline{N}_r\right|\quad(\text{净购电波动})$$

其中 $\overline{N}_r$ 为净购电均值，$f_4$ 即平均绝对偏差（MAD）。多目标处理采用两种方式：

1. **逐目标最优 + 字典序**：分别最小化 $f_1\sim f_4$，并在保持主目标最优的前提下以运行成本为二级目标进行两阶段求解，避免主目标最优解不唯一导致策略随意（如低碳最优放弃外送收益）。
2. **加权归一化综合权衡**：以附件基线的指标值为基准归一化，求解

$$\min \sum_{k=1}^{4} w_k \frac{f_k}{\left|f_{k}^{base}\right|}$$

取权重 $w=(0.35,0.30,0.15,0.20)$ 对应成本、碳排、峰值、波动。归一化基准取基线值而非单目标最优值，避免目标最优值为 0 时归一化失效。

## 6.5 求解算法

### 算法 3：区域储能协同优化（MILP）

```
输入：区域 r 的逐时负荷/新能源/电价/碳强度、储能参数、目标与权重
输出：逐时购售电、充放电、新能源分配与 SOC 轨迹

1. 按 6.4.3 构建约束矩阵（等式：新能源平衡、功率平衡、SOC 递推、均值；
   不等式：功率/边界/互斥/终态 SOC）
2. 若为逐目标最优：求解主目标 MILP，再追加“主目标 ≤ f_k* + tol”约束，
   以运行成本为二级目标求解
3. 若为综合权衡：按基线归一化权重构建单一目标求解
4. 校验：SOC 递推、功率平衡、充放电互斥、购售电边界、终态 SOC 逐项核验
```

六区域相互独立，可并行求解；每个 MILP 含约 2.4 万个变量、2.4 万个约束与 2407 个 0-1 变量，采用 scipy-HiGHS 求解，单区域单目标求解时间约 1–3 秒。

## 6.8 模型检验

对全部场景逐项校验（结果见 `结果/constraints_check.json`）：

1. **统一功率平衡**：按附件 1 公式 $GridPurchase+AvailableRenewable+Discharge=Total\_Load+Charge+GridSell+Curtailment$ 逐时核算，优化场景最大残差不超过 $10^{-4}$ MW。
2. **SOC 递推与边界**：SOC 递推残差不超过 $10^{-6}$ MWh；SOC 始终位于上下限内；$S(2406)\ge S^{0}$ 全部满足。
3. **功率与互斥**：充放电功率不超上限，且无同时充放电现象。
4. **购售电边界**：购电不超过 `MaxGridImport`，外送不超过 `SellLimit`。
5. **时域一致性**：第 2406 小时所有优化场景购电均为 0，负荷由新能源全额覆盖，仅用于终端状态结算。

此外，附件基线数据自身存在不一致：RegionE 的 SOC 递推残差约 1 MWh，且 D/E/F 区域终态 $S(2406)$ 分别仅 226.0/217.2/189.2 MWh，明显低于初始 SOC（405/370/382.5 MWh），不满足问题三的终态约束。这说明基线的运行状态并非严格满足全部约束的可行解，模型对基线的改善包含了储能终态“补齐”的贡献，正文对比时已按同一口径核算。

## 6.9 模型评价

**优点**：（1）模型与附件 1 口径严格一致（负荷折算、SOC 递推、碳排与新能源利用率公式逐项对齐）；（2）采用精确 MILP 求解而非启发式，可在给定条件下得到全局最优解，结果可复现；（3）通过 0-1 互斥变量避免物理上不可能的同时充放电；（4）逐目标字典序与加权归一化两种多目标处理方式互补，并附带容量与效率敏感性分析，结论稳健。

**不足与改进方向**：（1）未考虑储能寿命衰减、充放电循环次数成本与功率爬坡限制，可引入循环寿命惩罚项扩展为非线性模型；（2）模型假设各区域独立，未建模跨区输电约束；问题四中可将其纳入统一优化；（3）弃电未设惩罚成本，若引入新能源消纳激励，策略可能进一步向消纳倾斜；（4）负荷与新能源出力均为确定性输入，可结合问题一的预测模型开展随机/滚动鲁棒优化，考察新能源预测误差下的储能鲁棒策略。
